# SO-101 pose terminology

All tuples below are raw STS3215 encoder ticks in motor order: shoulder pan (1), shoulder lift (2), elbow flex (3), wrist flex (4), wrist roll (5), gripper (6). They belong to this assembled arm and its `care_reach_follower` calibration; they are not transferable to another arm without measurement.

| Term | Raw ticks | Meaning |
| --- | --- | --- |
| **Home / Retract** | `(2000, 1056, 3065, 2027, 387, 1993)` | The current retracted pose, physically set by Lance and stored in [`home_pose.json`](../home_pose.json). Torque was enabled at capture. |
| **Extend** | `(2000, 1903, 1126, 1988, 387, 1993)` | The upright pose derived from the official SO-101 model, then reached and visually confirmed by Lance with the wrist camera attached. Stored in [`extended_pose.json`](../extended_pose.json). The settled encoders were approximately `(2007, 1893, 1124, 1989, 387, 1984)` with torque on and no faults. |
| **Folded** | `(2040, 893, 3064, 2888, 2416, 1470)` | **Historical only.** Lance recorded this pose before adding the wrist camera. The camera now obstructs it; the dashboard rejects Fold and `park.py --execute` refuses to open the bus. Keep [`folded_pose.json`](../folded_pose.json) for provenance. |
| **Parked / Coiled** | No current target | Older terms for a compact rest. They are not commands in the camera-mounted setup. Home is the available retracted pose; no torque-release pose has been validated. |

## Motion rules

- Check the current measured pose, clear workspace, torque, voltage, fault flags, and saved limits before motion. A pose file records an endpoint, not the current arm position.
- Only one process opens the URT-2 serial port. Stop the Pi dashboard service before a standalone `home.py`, `dance_demo.py`, or another controller; start it again afterward. `park.py` is offline-only now.
- The dashboard's Home / Retract and Extend buttons move all six joints through the panel's bus owner. The Home↔Extend corridor follows a synchronized quintic trajectory with measured feedback and at most 55 ticks of commanded lead per joint. Model forward kinematics predicts a rising tool path from Home to Extend; the physical upright endpoint was confirmed. Before and during motion, the controller checks bounds, firmware limits, torque, status, voltage, load, and progress. On success it holds the exact target; cancel, fault, or service restart holds measured position. Torque stays on.
- The dashboard's Dance button uses the same bus owner and full-size `dance_demo.py` plan. From Extend it returns to Home on the synchronized corridor, then moves to the ordinary-bounds choreography center `(2000,)*6`, plays the dance at up to 20 Hz, and returns to Home. The button shows progress and cancels the active dance when pressed again. Competing jog and pose commands stay disabled; cancellation or a fault holds the measured pose with torque on. The new Dance-from-Extend path passed fake-bus tests; a live run with the wrist camera is still pending.
- Live dashboard checks on 2026-10-24: one complete full-size run finished near the former `(2000,)*6` choreography center with no faults. Two other runs stopped on a transient motor 6 status `1`, which the [ST-series memory table](https://docs.waveshare.com/Memory_Map_Explanation/ST_Servo_Memory_Map_Explanation) identifies as a voltage alarm. Later readings returned to 5.1–5.4 V and status 0, so the brief low point was not captured. The software keeps the immediate fault stop. Inspect the 5 V/4 A arm supply and power connections on both servo branches (1→2 and 3→4→5→6) before relying on repeated dances; [six 7.4 V servos](https://docs.waveshare.com/ST3215_Servo) can draw more than that supply during simultaneous acceleration. The dashboard now labels this status as a voltage alarm.
- The stored Folded pose has a historical motor 2 exception below its ordinary panel bound, but no live Fold command uses it. `park.py --execute` refuses immediately. Motor 3's ordinary upper bound is 3065, exactly the recorded Home tick. Trim commands never exceed it.
- None of these scripts automatically disables torque. Before any future torque-release function is added, validate a pose that remains mechanically supported after the wheelchair mount, then test its hold and release behavior under that mounting.
- The jaw's measured contact was 1317 ticks, but ordinary position-mode motion uses a provisional 1340-tick lower stop. Motor 5 encountered resistance near 3358 ticks, so ordinary motion stops at or below 3300.

The panel's saved bounds and speed scales live in [`joint_settings.json`](../joint_settings.json). The LeRobot calibration backup is [`config/care_reach_follower.json`](../config/care_reach_follower.json); the active Pi copy lives in the LeRobot calibration cache. If a joint is rebuilt or recalibrated, review both records and revalidate the pose path before replay.
